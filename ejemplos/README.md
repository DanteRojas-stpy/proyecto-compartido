# Cotizaciones de ejemplo

Caso de prueba completo para medir si la plataforma acierta:

- `entradas/`: itemizado de partidas, matriz de procura, lista de proveedores.
- `cotizaciones/`: las cotizaciones recibidas (PDF, Excel, Word, fotos).
- `esperado/`: la matriz comparativa llenada a mano (resultado correcto).

Antes de subir una, borra nombres, RUC, teléfonos y correos del proveedor.
