# Prompts de la IA

Las instrucciones que se le dan al modelo de IA para leer correos y documentos,
detectar aclaraciones y proponer homologaciones.

## Reglas

1. Cada prompt es un archivo de texto (`.md`) con un nombre claro, por ejemplo
   `lectura-cotizacion.md` o `deteccion-aclaraciones.md`.
2. Un cambio de prompt entra por Pull Request, igual que el código, porque
   cambia la forma en que el sistema decide.
3. La IA **propone**; no decide por sí sola. Toda homologación sin evidencia o
   sin aprobación del especialista queda marcada para revisión.
